# Modern GUI - Modrinth page copy

## description

A shared menu library with clear text, rounded panels and familiar controls for Minecraft mods.

## body

Modern GUI provides the buttons, panels and other controls used by mods built with it.

It gives menus a consistent look, with clear text, rounded panels, scrolling lists and familiar settings controls.

### Installation

Install Modern GUI when another mod asks for it, along with Fabric API. Most players will receive it as a required download for another mod.

You can open **/moderngui** to try the included widget showcase.

### Credits

Modern GUI uses the Inter font and icons from Lucide. Their license notices are included with the library.
